# Luma 1.0.0

Подписанный установочный пакет для Android: `Luma-1.0.0.apk`.

## Состав

- C# / .NET 8 for Android, нативный Canvas.
- Android 7.0 (API 24) и новее; целевой API 34.
- ARM64, ARMv7, x86-64 в одном APK.
- Идентификатор приложения: `com.lumastudio.matchthree`.
- 30 уровней, бесконечный режим, усилители, достижения и локальные сохранения.
- Оригинальный прозрачный PNG-логотип, обычная и адаптивная иконки Android.

## Выполненные проверки

Во время разработки проверены правила на 11 444 смоделированных ходах:
94 055 утверждений завершились успешно. Проверки включали каскады,
спецкристаллы, лёд, расход усилителей, завершение уровней и сохранения.

Release APK установлен и главный экран открыт в ARMv7-эмуляторе Android 7.0.
Физический Android-телефон в этой среде не подключался; производительность
и поведение на конкретных моделях телефонов здесь не измерялись.

Ключ подписи хранится отдельно, в соседней папке `Luma-Signing`.
Для выпуска обновлений нужен тот же ключ. В архив исходников он не включён.
